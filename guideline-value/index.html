How to read the result

What TNREGINET shows you

  1. Survey / subdivision number and its land classification (wet, dry, dry special, house site, etc.).
  2. Guideline value per acre (British value) and per hectare (metric value) for land, or per square foot / square metre for street-wise urban property.
  3. Effective start date — the current revision applies from 1 July 2024 unless a later date is shown for that survey number.
  4. A value of 0 / "Govt. Others" means the land is classified as government land.

Guideline value is the minimum value on which stamp duty and registration fee are charged — it is not the market value. The result comes directly from the Registration Department's site (tnreginet.gov.in); for use in a document or legal opinion, obtain a certified guideline value from the SRO. If the survey number is not found, it may have been re-subdivided — check the latest Patta / A-Register.
